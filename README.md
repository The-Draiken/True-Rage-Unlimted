# True Rage Unlimited

There's a bunch of Mods out there in the wild that already make Rage unlimited, but the issue is every subclass of a Barbarian has it's own individual rage that generally isn't covered by any of these mods and such on higher levels rage acts like it's vanilla self again.

## What it changes

- **No more 10-turn limit.** Every Rage now lasts until it ends for another reason.
- **The core rule stays.** As in tabletop D&D, Rage still ends if the Barbarian goes a full turn **without attacking an enemy or taking damage**. When that happens, a **"Rage Ended"** message appears above them and Rage is cleaned up automatically.
- **You can still end it yourself** with **End Rage**.
- **Cost is unchanged.** Raging still costs a **bonus action and one Rage charge**.

## Covered Rages

| Subclass | Rage |
|---|---|
| All Barbarians | Rage |
| Berserker | Frenzy |
| Wildheart | Bear Heart, Eagle Heart, Elk Heart, Tiger Heart, Wolf Heart |
| Wild Magic | Rage: Wild Magic |
| Path of Giants | Giant's Rage, including the Colossus forms (Large and Huge) |

The level 9 versions of each Rage are covered too. It also includes support for the **Rage Mage** Rage (`MHRAGE_RAGE`) from a separate subclass mod.

## Bonus change
- **Imp familiar Invisibility:** the Imp's Invisibility no longer has a time limit. It is still a concentration spell.

## Requirements
None. This is a stats-only mod and does **not** need the Script Extender.

## Installation
1. Install with your mod manager of choice.
2. Place it **before** any mod that builds on it, such as **Karlach's Rage**.

## Compatibility
- Affects **every** Barbarian, including companions, hirelings and enemy Barbarians.
- Overrides the Rage statuses (`RAGE`, `RAGE_FRENZY`, `RAGE_TOTEM_*` and their `_2` versions) and the Rage spells (`Shout_Rage*`). Other mods that change the same entries will conflict, and whichever loads last wins.
